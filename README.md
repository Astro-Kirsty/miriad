# miriad
This repository contains Miriad scripts for use within the HEAG. It provides users with various simple scripts, to perform various tasks on gas data or to change the orientation of data cubes.
These methods are commonly used within the HEAG, for any further questions on these scripts please contact me.

## Installation
The installation/updating guide for miriad can be found at https://www.atnf.csiro.au/computing/software/miriad/INSTALL.html

## Documentation 
The user guide for miriad can be found at https://lweb.cfa.harvard.edu/sma/miriad/manuals/ATNFuserguide_US.pdf
The information on each `task' used in this repository can be found at https://www.atnf.csiro.au/computing/software/miriad/taskindex.html
